The ZeroClaw app

A private publishing tool used only by the ZeroClaw operator for ZeroClaw's own accounts; no sign-up, no service to other people. On YouTube it uploads ZeroClaw's own shorts after the operator approves each post, reads the channel's own statistics, and drafts replies to comments that the operator approves before they are posted (YouTube Data API and YouTube Analytics API via Google sign-in). The same approved videos go to ZeroClaw's own Instagram, X and Bluesky accounts through their official APIs.
